# VEYRA — Personal Control Center

VEYRA is a responsive, dark-first personal workspace designed to keep everyday work in one calm, focused place.

## Open the website
Visit the repository's `index.html` file or enable a static hosting provider to publish it. Hosting has not been configured or deployed by this commit.

## Features in this starter
- Responsive overview dashboard and navigation
- Task list with completion tracking and progress
- Scratchpad with automatic local saving
- Recent activity timeline
- Command palette with **Ctrl/⌘ + K**
- Light and dark appearance toggle
- Export local workspace data as JSON
- Reset local workspace data

## Run locally
Download the repository and open `index.html` in a modern browser. There is no build step, package manager, API key, or backend required.

## Data and privacy
This starter stores tasks, notes, appearance preferences, and activity in the browser's `localStorage`. The data is not synced between devices and there are no user accounts, cloud database, or connected external services yet. Avoid storing sensitive information in the scratchpad on a shared device. Export important data before clearing browser storage.

## Free static hosting
This is a static HTML site and can be deployed on a free static hosting tier such as Cloudflare Pages. Use the repository root as the project directory and leave the build command empty. Check the provider's current free-tier limits before enabling any optional services. No paid services or domain purchases are required for local use.

## Roadmap
Possible next stages include splitting the app into maintainable modules, adding accessible keyboard navigation, optional secure cloud sync, and real integrations. Cloud accounts and integrations should be added only after their authentication, data handling, and free-tier limits are designed.
